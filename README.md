# PROXINET Old Website Replica

Source replacement files for the `sab0o/proxinet-old` Next.js repository.

## Apply these files
Copy the `app` directory in this archive into the root of your local `proxinet-old` repository and replace the existing files when prompted. The existing `public/images` directory already contains the image assets used by these pages, so keep it unchanged.

## Run
```bash
npm install
npm run dev
```
Open http://localhost:3000.

Pages reconstructed from the supplied screen recording and image assets: Home, Information, Profile, Product (Paket Internet Lainnya, Paket Internet Home, PROXINET Mitra), Contact Us, and FAQ. The FAQ input and dropdown navigation are interactive.
